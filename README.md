## 更新记录：
    - 整体优化：修复脚本声明顺序问题；三个关于页共用一份导航页脚（common.js）；
      关于页展示角色立绘；统一 CSS 格式并修复下拉菜单宽度
    - 接入 AI 对话：新增设置面板（API 地址 / 秘钥 / 模型 / 角色设定，目前支持 DeepSeek，
      秘钥保存在本地浏览器）；首页聊天接入真实大模型回复
    - 界面调整：彻底删除开场动画（含加载页，进入即登录或首页）；聊天气泡缩小；
      聊天栏宽度砍半；侧边栏改为纯白、支持自由展开/收起（默认收起）；
      设置改为独立页面（settings.html）；全站字体调大 2px
    - 体验升级：侧边栏收起后保留网站图标（40px 窄条），鼠标移入自动展开、移出收回；
      展开宽度再缩减；聊天区与输入框左沿对齐，输入框上下压缩；等待回复改为三点跳动；
      气泡出现动画（上滑 + 由小变大，左右区分）；设置页重新排版（左上角返回 + 左侧导航），
      API 提供商支持添加多个并自由切换（「添加 API」弹窗由快到慢出现）
    - 多服务商与本地隐私：侧边栏收起 44px（图标两侧 5px），展开 135px，收回响应 0.1s；
      删除「我的」菜单，点击头像进入用户设置（user.html）；对话历史默认展示最近 3 对
      （设置页可调 1~20 对），完整历史存本地、侧边栏「对话」可查看（chat-history.html）；
      设置页三视图（AI 对话 / 角色设定 / 对话历史），返回按钮改圆形白底；
      弹窗圆润、无滚动条、点空白关闭、重名自动编号；新增通义千问服务商；
      模型输入框点击自动获取并列出服务商模型；全站背景改白色
    - 导航与对话升级：侧边栏展开再小 30%（95px），新增插画 / 周边 / 动态真实跳转页
      （装修中占位），「关于」改为 hover 展开子菜单（星瑶 / 月瓷 / 小喵，带装修徽章）；
      主页对话区默认只展示设置的 N 对，可「展开全部」查看完整历史（状态记忆，
      每次打开自动接续上次对话）；「对话」跳转设置页「对话」视图（含保留对数 +
      清空 + 全部历史）；设置页导航与主页一致，「API 设置」卡片点击即切换当前模型；
      角色设定改为多角色卡片管理（添加 / 点击切换 / 删除，数据存本地）
    - 精简与统一：主页侧边栏删掉「对话」项、菜单按钮变大（44px 高）；聊天区左上角
      「对话」标题去掉，对话默认展开显示全部历史（可点「收起」只显示 N 对）；
      设置页除边栏外内容区加宽适配；「API 服务商」改为自定义下拉（与页面风格统一）；
      对话记录默认折叠成一行，支持点击展开 / 修改 / 删除；
      各子页面顶部导航只保留「插画 / 周边 / 动态 / 关于」，样式与主页统一（横排圆角）
    - 修复与会话化：修复设置页脚本中断导致 API 列表空白的问题（缺失元素声明）与
      名称被覆盖的问题；侧边栏扩大 5%（100px），菜单点击范围占满整行（主页与设置页一致）；
      对话历史改为按角色会话分组（不同角色各自独立的历史），每个会话折叠成一张卡片，
      点击展开全部消息，支持修改 / 删除单条消息与整个会话；旧版历史自动迁移
    - 站长专属角色设定：角色设定内容（System Prompt）不再写入公开代码，只保存在
      站长自己的浏览器中；「角色设定」增加站长口令锁（首次设置口令，之后输入口令进入，
      可重置 / 修改口令）；解锁后自动准备「星瑶」「月瓷」两个空文本角色供站长填写，
      普通访客只能看到锁界面
