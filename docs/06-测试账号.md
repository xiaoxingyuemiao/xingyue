## 需要再加测试账号时

Supabase 后台手动加（假邮箱也能加，不需要邮箱验证）：

1. **Authentication → Users → Add user → Create new user**
2. 填邮箱 + 密码
3. ⚠️ **必须勾上 `Auto Confirm User`** —— 不勾的话密码登录会被拒绝，提示"邮箱还没有验证"
4. 点 **Create user**
5. ⚠️ **回到 SQL Editor，再跑一遍 `tools/supabase-schema.sql` 里「补齐历史用户」那一段**
   （后台手动建的账号**不会**触发 `on_auth_user_created`，不补的话 `profiles` 里没有它的行，
   登录时会报 `23502 null value in column "uid"` —— 账号二就是这么踩的）

> **两个测试账号还有个用处**：互相切换登录，测「换账号时本地残留有没有被清掉」
> （以前会看到上一个账号的昵称 / 头像，现在应该只显示自己的）。

## 要测「验证码 / 忘记密码」怎么办

那两个流程需要**能真的收到邮件**，所以：

- 用**自己的真实邮箱**注册一个账号（会真的收到 6~8 位验证码）
- 或者临时关掉邮箱验证：**Authentication → Sign In / Providers → Email → 把 `Confirm email` 关掉**
  （关掉后任何邮箱都能直接注册；测完记得**打开**，否则访客可以瞎填邮箱）
