API 设置

配置 api 接口。秘钥默认只保存在你自己的浏览器里； 登录后可以勾选下面的选项，把它加密同步到云端，换设备就不用重填了。

说明：加密密钥由登录账号派生。换设备时请先登录同一个账号，再开启此选项，云端秘钥才能解开。

我的角色

添加你自己的角色，支持多个角色，点击卡片切换当前角色， 数据只保存在你自己的浏览器里。 没有选择自己的角色时，聊天默认使用网站的官方角色设定。

对话

对话历史保存在你的浏览器本地；登录状态下会自动同步到星月小窝后端， 换设备登录同账号即可带回。未登录时只留在本机，不会上传。 每个角色各自独立一份对话历史（切换角色会切换对应的历史）， 主页只显示最近一轮对话（气泡），历史记录全部保留。
