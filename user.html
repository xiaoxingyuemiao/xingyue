API 设置

配置 api 接口，秘钥只保存在你自己的浏览器里。 添加后点击对应的模型即可切换聊天使用的模型。

我的角色

添加你自己的角色，支持多个角色，点击卡片切换当前角色， 数据只保存在你自己的浏览器里。 没有选择自己的角色时，聊天默认使用网站的官方角色设定。

对话

对话历史等重要隐私数据只保存在你的浏览器本地，不会上传。 每个角色各自独立一份对话历史（切换角色会切换对应的历史）， 主页只显示最近一轮对话（气泡），历史记录全部保留在本地。
